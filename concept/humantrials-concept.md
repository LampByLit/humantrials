Human Trials:

this game should be a 3d FPS but instead of a shooter it is a chemistry simulator. primary gameplay involves pouring liquids from containers into other containers, processing them, mixing them, etc, using a somewhat janky at first control system that improves the more you make and take medicines that affect you in different ways. also you can test the chems on rats. the fun should be how difficult it is to initially pick things up and pour them and use them etc. i played a game called heavenly bodies lately that sort of uses the concept of using the controls to make the game interesting. the chemicals will not be the standard elements, instead all possible chemicals will be represented by a hex color, and each hue area of the spectrum will have different chemical properties, ex red is acid or something; maybe there are only three elements, red blue and green, and all hex molecules can be constructed using those three elements.
